# Contributing

Thanks for your interest in improving this project!

## Getting started
1. Fork the repository and clone your fork.
2. Open the project in Android Studio (latest stable).
3. Let Gradle sync, then run the `app` configuration on an emulator or device.

## Making changes
- Create a branch: `git checkout -b feature/short-description`
- Follow the official Kotlin coding conventions.
- Keep commits small, with clear messages.
- Open a Pull Request describing what changed and why.

## Reporting bugs / requesting features
Open a GitHub Issue with steps to reproduce, expected vs. actual behavior,
and your Android version/device.

## Code of Conduct
All contributors must follow our [Code of Conduct](CODE_OF_CONDUCT.md).
